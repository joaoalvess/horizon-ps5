# Fork fixes for Donkey Kong Bananza and Mario Tennis Fever

Writer: the fork-research agent (2026-11-06 20:15). Scope: fixes in the community forks of Eglantine that help Donkey Kong Bananza (`040074A01BF12000`, the owner's v458752, main build ID `E25C90C1C136638885659FD55BF8A03B3403489D`, `dm/games/040074A01BF12000/game.tsv` line 16 in the Mac repo) or Mario Tennis Fever (`0400D4201C6EA000`) on the PS5 port that `v2` does not have yet. The check is a [port-log](../port-log.md) row, a `cherry picked from commit` line in `git log v2`, or a grep, quoted. Commits that stack were checked in a scratch copy of the touched files, never in core-v2.

PS5 facts used below (`headless/main.cpp` in the worktree):
- gpu_accuracy is set High every session (lines 849 and 1142). `GpuSplit::MaybeStart` (gpu_split.cpp:100-104) starts only when the level is not High. So DK runs without the GPU split by default. Tennis gets Low from `Core::GameSettings::LoadOverrides`, so it runs with the split.
- Reactive flushing is off unless chosen.
- `EDEN_NX2_UNSAFE_PREEMPTIVE_READS=1` and `EDEN_NX2_SPARSE_UNBACKED=1` are set (line 521). The latter overrides `CanUseUnbackedSparseImages`, which already excludes AMD and RADV.
- DK gets `EDEN_NX2_SOFT_HMMA=1` (lines 1173-1185). HMMA is therefore lowered, and the upscaler stand-in, which runs only when HMMA is not lowered, never runs.
- The GPU clock is core's default, Boost (settings.h:637).
- Asynchronous shaders stay at the default, off (settings.h:666).
- Mods load from the game files folder's `mods/`, with a Library toggle per mod (lines 790-793 and 1168-1188).
- RADV has neither VK_NV_geometry_shader_passthrough nor VK_NV_viewport_array2, so passthrough geometry is lowered. Its maxGeometryOutputComponents is 128.
